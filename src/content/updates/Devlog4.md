## Our First dev talk
A few days ago, we had our first dev talk. In this dev talk,
I and our directors where going through the current game and talked about what the plans for the different levels are.

This talk was very important for us to get a clear understanding of what we need to work on next
and to clean up any misunderstandings.

Another reason for this dev talk was to make is easyer for new developers to get started.
for that reason, we recorded the dev talk and made it available on our [YouTube channel](https://www.youtube.com/@TeamFiltered).
For now, we are keeping it unlisted, but we plan to make it public at some point in the future.

We also plan on releasing the uncut version of the Stream when the first chapter is released.

But if you are interested in joining us, you can still watch [the video](https://www.youtube.com/watch?v=VsUPUEL553w) here, but be warned that it may contain spoilers.

## Chapter 6 changes
After thinking about it for a while, we decided to change the theme for chapter 6.

Chapter 6 was originally planned to be a Superhero-themed level in a modern setting.
But because we didn't have enough ideas for how to design it, we decided to change the theme.

The new theme will be a steampunk-mystery level.
this doesn't have much effect on the story, as it was already planned to be a mystery level.
Now just with a more fitting and hopefully interesting theme.

## We still need help
If you are interested in developing a game, know how to use github
and think you can do level design, programming or art, we would love to have you on board!

The main things we need help with are level design, programming and art.
- We did get some more artists form the posters but still need animators.
- Level design is also a big problem, I'm can come up with ideas but need help with turning them into a real concept the artists can work with.
- Right now we only have one main programmer working on the project. And he could really use some help, though this is currently the least important part of the project.

Even if you are not a developer, you can still help us by making sugestions and by telling us what you think.
Also, if you know someone who might be interested in joining us, please tell them about our project!
